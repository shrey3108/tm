# Push Backend Command

```yaml
---
description: "Push only backend changes to the Git repository."
---
```

Push only the backend code changes to the current Git repository.

## Instructions

* Stage only backend-related files.
* Do not include frontend, documentation, or unrelated changes.
* Create a commit with a meaningful commit message if required.
* Push the changes to the current branch.
* Display the commit hash and confirm the push was successful.
* If there are merge conflicts or push errors, stop and display the error without attempting to resolve it automatically.
